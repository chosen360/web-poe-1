 Fables World of Games

A first-year web development project showcasing HTML, CSS, JavaScript, and SEO.  
The site shares adventure, puzzle, and RPG games with a simple design and interactive features.

   Overview
- Responsive layout with grid and hover effects
- Gallery with lightbox (click images to enlarge)
- Accordion FAQ section
- Contact and Enquiry forms with validation
- Dynamic content filtering (search and categories)
- SEO setup: robots.txt and sitemap.xml
- Accessibility: alt text, labels, semantic HTML


Tech Stack
HTML5, CSS3
Vanilla JavaScript
JSON data for listings
GitHub Pages for hosting
